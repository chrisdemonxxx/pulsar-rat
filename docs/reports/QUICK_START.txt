## QUICK TROUBLESHOOTING

| Problem | Fix |
|---------|-----|
| "Address already in use" | `taskkill /F /IM Pulsar.exe` |
| Port 4783 still in use | Wait 30 seconds, try again |
| Immediate crash | Check framework: `dotnet --version` |
| No connection | Check firewall allows port 4783 |
| Both stuck/hanging | Kill both: `taskkill /F /IM Pulsar.exe` and `taskkill /F /IM Client.exe` |
