🆘 TROUBLESHOOTING:

   Problem: "Client doesn't appear in list"
   Fix: Wait 5-10 seconds and refresh (F5) the Server Panel
   
   Problem: "HVNC won't open"
   Fix: Make sure you double-clicked or right-clicked properly
        Check the client is still connected (green indicator)
   
   Problem: "Black screen in HVNC viewer"
   Fix: The client is running headless. Run on a machine with display
        OR use HVNC Desktop Streaming (server will mirror display)
   
   Problem: "Mouse/keyboard not responding"
   Fix: Click inside the HVNC viewer to focus it
        Try right-click to regain focus
   
   Problem: "Connection dropped"
   Fix: Client reconnects automatically after 30 seconds
        If not, restart both Pulsar.exe and Client.exe

🚀 WHAT'S HAPPENING UNDER THE HOOD:

   1. Client captures desktop using Windows DXGI
   2. Frames encoded to H.264 in real-time
   3. Each frame encrypted with session key
   4. Packets transmitted to Server over TLS
   5. Server decrypts and displays in HVNC viewer
   6. User input captured and sent back encrypted
   7. Client applies input (mouse moves, clicks, typing)
   
   This happens seamlessly in real-time at <100ms latency!
